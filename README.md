# Calculadora Python

Una calculadora con interfaz gráfica desarrollada en Python utilizando Tkinter. Simple de usar, intuitiva y perfecta para aprender sobre interfaces gráficas en Python.

## Características

- Operaciones básicas: suma, resta, multiplicación y división
- Operaciones avanzadas: división entera, potencia y módulo
- Interfaz gráfica amigable con Tkinter
- Botones numerados del 0 al 9 y punto decimal
- Función de borrar (AC) y botón de retroceso
- Validaciones y manejo de errores
- Detección de división entre cero

## Requisitos

- Python 3.x
- Tkinter 

## Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/FedeJGM/Calculadora-Python.git
cd Calculadora-Python
```

2. Ejecuta el archivo:

```bash
python calculadora-python.py
```

Eso es todo. La calculadora se abrirá en una ventana.

## Cómo usar

1. Ingresa el primer valor: Haz clic en los números que deseas
2. Selecciona una operación: Presiona uno de los botones de operación (+, -, *, /, etc.)
3. Ingresa el segundo valor: Vuelve a ingresar números
4. Obtén el resultado: Presiona el botón "="

### Botones disponibles:

| Botón | Función |
|-------|---------|
| 1-9 | Números |
| . | Punto decimal |
| + | Suma |
| - | Resta |
| * | Multiplicación |
| / | División |
| // | División entera |
| ^ | Potencia |
| % | Módulo |
| AC | Limpiar todo |
| <- | Borrar último dígito |
| () | Paréntesis |
| = | Calcular resultado |

## Propósito

Este proyecto fue creado como parte de un curso de Python para demostrar:

- Uso de interfaz gráfica con Tkinter
- Manejo de eventos y funciones lambda
- Validación de datos y manejo de excepciones
- Gestión de estado en aplicaciones

## Notas

- La calculadora valida que los valores ingresados sean válidos
- Muestra mensajes de error para divisiones entre cero
- Convierte resultados decimales a enteros cuando es apropiado
